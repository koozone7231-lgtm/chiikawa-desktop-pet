# 먼작귀 펫 🐾

바탕화면 아래(작업표시줄 위)를 **치이카와 · 하치와레 · 우사기**와 친구들이 돌아다니는 Windows 데스크톱 펫입니다.
8명 중에서 골라 **한 번에 5마리까지** 바탕화면에 둘 수 있어요.
밥을 주고, 쓰다듬고, 공놀이를 하며 키우고, 펫을 눌러 자주 쓰는 웹페이지나 앱을 바로 열 수 있어요.
일하거나 공부할 때 방해되지 않는 "곁에 있는 귀여운 친구"가 목표예요.

> ⚠️ 팬이 만든 비공식 프로그램입니다. 치이카와(ちいかわ) 캐릭터의 권리는 원작자 나가노와 권리자에게 있으며, 이 프로젝트는 권리자와 관계가 없습니다. 개인적인 용도로만 사용해 주세요.

## 설치

1. [Releases](https://github.com/koozone7231-lgtm/chiikawa-desktop-pet/releases/latest)에서 `ChiikawaPet-Setup-<버전>.exe`를 내려받습니다.
2. 실행해서 설치합니다. 바탕화면과 시작 메뉴에 **먼작귀 펫** 바로가기가 생겨요.
3. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요. (코드 서명이 없어서 뜨는 경고예요.)

- 지원: Windows 10 / 11 (64비트)
- 한 번 설치하면 **새 버전이 자동으로 업데이트**돼요. 받아 둔 업데이트는 앱을 끌 때 설치되고, 바로 설치할 수도 있어요.

## 이렇게 놀아요

| 하는 법 | 일어나는 일 |
| --- | --- |
| 펫 **클릭** | 펫이 든 작은 메뉴가 열려요 — 🔗 숏컷 / 🎈 놀아주기 |
| 펫 **드래그** | 들어서 옮기고, 던지면 날아가요 |
| 펫 위에서 마우스를 **좌우로 문지르기** | 쓰다듬기 — 하트가 뜨고 기분이 좋아져요 |
| 트레이 아이콘 **클릭** | 펫 숨기기 / 보이기 |
| 트레이 아이콘 **더블클릭** | 설정 창 열기 |

### 🎈 놀아주기

- **간식 주기**: 🍙 주먹밥 · 🍮 푸딩 · 🍜 라면 (코인 사용)
- **쓰다듬기**, **⚽ 공놀이**(굴러간 공을 쫓아가서 잡아요), **재롱 보기**, **재우기 / 깨우기**
- 배부름 · 기분 · 기력이 시간이 지나며 천천히 줄어요. 오래 안 켜도 펫이 떠나거나 아프지 않아요.
- 켜 두기만 해도 5분마다 코인 1개(토벌 보상), 숏컷을 쓰면 코인과 친밀도가 조금씩 올라요.

### 🔗 숏컷

설정 → 숏컷에서 웹페이지 주소나 앱(.exe / 바로가기)을 등록하면, 펫 메뉴에서 골라 바로 열 수 있어요.
펫을 정해 두면 그 펫 메뉴 맨 위에 ★로 고정돼요. 트레이 → 숏컷에서도 열 수 있어요.

### 📖 집중 모드

트레이나 설정에서 켜면 펫들이 화면 아래에서 **얼굴만 내밀고 가만히 지켜봐요**.
뽀모도로 타이머(기본 25분 집중 / 5분 휴식)가 돌아가고, 시간이 되면 알려줘요.

### 캐릭터마다 달라요

| 캐릭터 | 성격 | 고유 행동 |
| --- | --- | --- |
| 치이카와 | 소심하지만 노력파 | 깜짝 놀라 울기 ("히익...!") |
| 하치와레 | 밝고 긍정적 | 노래 부르기, 치이카와가 울면 옆에서 달래기 (헌책방도 "괜찮아…?") |
| 우사기 | 예측불가 에너지 | 화면 끝까지 질주하며 소리 지르기 ("이하~!") |
| 랏코 | 엄격하지만 디저트를 좋아하는 스승님 | 앞장서서 질주 ("따라와라!") |
| 모몽가 | 칭찬받고 싶은 떼쟁이 | 귀여움 뽐내기 ("후후… 보라구, 이 귀여움을!") |
| 시사 | 성실하고 열정 넘치는 긍정왕 | 열심히 일하기 ("열심히 하겠습니다!") |
| 헌책방 | 수줍지만 다정한 헌책방 주인 | 앉아서 책 읽기, 모몽가를 만나면 "모몽가, 같이 가자" |
| 쿠리만쥬 | 여유로운 동네 미식가 | 앉아서 한잔 ("푸하-!") |

처음엔 치이카와 · 하치와레 · 우사기가 나오고, 나머지 친구는 설정 → 캐릭터나 트레이 → 캐릭터에서 켜요.

친구끼리 마주치면 같이 놀며 하트를 날리기도 해요.

## 설정

트레이 → **설정…** 에서 바꾸면 바로 저장되고 적용돼요.

- 🐾 **캐릭터**: 친구 켜고 끄기 (최대 5마리), 크기, 걷는 속도, 캐릭터 간격
- 💬 **행동·말풍선**: 혼잣말 빈도(자주 / 가끔 / 조용히), 친구끼리 놀기
- 📖 **집중·알림**: 집중 모드, 뽀모도로 시간, 얼굴 내미는 정도, 휴식 알림 간격
- 🔗 **숏컷**: 추가 · 수정 · 삭제
- 📊 **상태**: 코인, 친구별 배부름 · 기분 · 기력 · 친밀도
- ⚙️ **일반**: 업데이트 확인, 자동 업데이트, Windows 시작 시 자동 실행, 저장 폴더, 설정 초기화

키운 기록과 설정은 `%APPDATA%\chiikawa-desktop-pet`에 저장돼요. 앱을 지웠다 다시 깔아도 그대로 남아요.

## 개발

```
npm install
npm start
```

### 구조

| 경로 | 내용 |
| --- | --- |
| `src/main.js` | 투명·클릭 통과 창, 트레이, 설정·숏컷·저장 파일, 숏컷 실행 |
| `src/updater.js` | 자동 업데이트 (electron-updater, GitHub Releases) |
| `src/renderer/characters.js` | 캐릭터별 속도 · 고유 행동 · 대사, 간식 목록 |
| `src/renderer/pet.js` | 펫 한 마리의 상태 기계와 물리 |
| `src/renderer/app.js` | 마우스, 펫 메뉴, 공놀이, 타이머(휴식 알림 · 코인 · 뽀모도로), 저장 |
| `src/renderer/settings.*` | 설정 창 |
| `tools/make_sprites.py` | `assets/source/` 원본 그림의 배경을 지워 `assets/sprites/`에 투명 PNG 생성 |
| `tools/make_icon.py` | 스프라이트로 앱 아이콘 `build/icon.ico` 생성 |
| `build/afterPack.js` | 빌드한 exe에 아이콘·버전 정보 넣기 (rcedit) |

새 캐릭터는 `characters.js`에 한 항목, `assets/sprites/<id>.png` 한 장을 추가하면 돼요.

### 빌드와 배포

```
npm run dist      # dist/에 설치 파일과 포터블 exe 생성 (업로드 안 함)
npm run release   # 설치 파일을 GitHub Releases에 올림
```

새 버전 올리는 순서:

1. `package.json`의 `version`을 올립니다 (예: 0.1.1 → 0.1.2). 같은 버전은 업데이트로 인식되지 않아요.
2. PowerShell에서 토큰을 넣고 릴리스합니다. 토큰은 해당 저장소에 쓰기 권한이 있는 GitHub Personal Access Token이에요.

   ```
   $env:GH_TOKEN = "토큰"
   npm run release
   ```

3. Releases에 `v<버전>`과 `latest.yml`이 올라가면, 설치된 앱들이 15초 뒤 / 4시간마다 확인해서 새 버전을 받아요.

포터블 exe와 `npm start` 개발 실행에서는 자동 업데이트가 동작하지 않아요.
